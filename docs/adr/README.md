# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for the 3D Print Platform.

## Status
- Proposed
- Accepted
- Superseded
- Deprecated

## Rule
When a major decision changes, create a new ADR and mark the old one as Superseded. Do not silently rewrite decision history.

## Baseline ADRs
- 0001 — Modular Monolith
- 0002 — PostgreSQL
- 0003 — Redis + BullMQ
- 0004 — S3-compatible Object Storage
- 0005 — External Provider Adapters
- 0006 — Mobile + OTP Customer Authentication
- 0007 — Persian-first / RTL-first
- 0008 — Docs-as-Code
- 0009 — Transactional Outbox
- 0010 — Next.js + NestJS + TypeScript
